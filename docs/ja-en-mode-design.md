# 日→英モード (JA→EN) 設計メモ

「自分が実際に言いそうな日本語」を大量に並べ、それを英語に置き換えて練習するモード。
既存の英語主役のフレーズ機能とは **別モード** として作り、必要になった文だけを
既存のフレーズ (音読・暗唱・録音) に流し込む。

## 全体像

```
src/data/jaCorpus/        日本語コーパス本体 (リポジトリ内の静的データ)
  types.ts                JaDomain / JaSentenceInput / JaSentence
  domains.ts              89 分野 × 9 グループの定義 (target = 目標文数)
  d01Morning.ts 〜 d89ChunkExtras.ts  分野 01〜89 の文
  index.ts                ID 採番・検索・集計。分野を書いたらここに 1 行足す

src/data/chunkBuilder.ts     組み合わせ練習の部品 (言い出し 40 / 動詞 60 / 補足 30)
src/utils/jaCorpusReview.ts  評価(◎○△×)・メモ・書き出し・フレーズ化
src/utils/srs.ts             間隔反復 (出題間隔・XP 計算)
src/utils/dailyPlan.ts       「今日の N 文」の組み立て (出題範囲の絞り込みもここ)
src/utils/practiceFocus.ts   出題範囲 (全分野 / グループ / 分野ひとつ) の保存
src/utils/chunkPractice.ts   組み合わせ練習の回数 (SRS にも XP にも乗せない)
src/pages/JaEnPage.tsx       /ja-en の画面 (コーパス一覧)
src/pages/JaEnTodayPage.tsx  /ja-en/today の画面 (今日の練習)
src/pages/ChunkBuildPage.tsx /ja-en/build の画面 (組み合わせ練習)
```

## データ 1 文が持つ情報

| フィールド | 内容 |
| --- | --- |
| `ja` | 自分が実際に言いそうな完全な日本語 |
| `en` | 会話で自然に使える英語 |
| `ch` | 反復して覚える英語のチャンク |
| `scene` | 場面 (家、駅、カフェ、仕事 など) |
| `to` | 相手 (家族、友人、店員、同僚 など) |
| `imp` | 重要度 `must` (必須) / `often` (よく使う) / `sub` (補助) |
| `pat` | 英会話の型 (例 `"I'm about to ~"`)。持たない文は空。カードと今日の練習に「型」として出る |
| `by` | 出所 `self` (本人が書いた文) / `add` (口調を寄せて足した提案文)。データファイル側では `*_SELF` / `*_ADD` の 2 配列に分けて書き、`index.ts` で付与する。あとから本人の文を足すときは `RAW_BY_DOMAIN` の `late` に入れる (末尾に付くので既存の ID がずれない) |

読み上げは `en` をそのまま Web Speech API に渡すので、音声用の別フィールドは持たない。

## ID 規約

`d<分野番号2桁>_<分野内連番3桁>` (例: `d01_003`)。

- 連番は **配列の並び順から自動採番** する (データ側に id は書かない)。
- そのため **既存の文を途中に挿入したり並べ替えると、評価が別の文にずれる**。
  - 追加は原則 **末尾に足す**。
  - 文を差し替えたときのために、評価には「評価した時点の日本語」を一緒に保存していて、
    ずれた文はカードに ⚠ を出す。
- フレーズ化したときの Phrase ID は `custom_jc_d01_003`。`custom_` 始まりなので
  既存の自作フレーズ・音声メモ・同期にそのまま乗り、何度取り込んでも増殖しない。

## 画面でできること

- 分野を選ぶ (グループ 9 つ → 分野のプルダウン)。全分野横断の検索も可 (**型でも検索できる**)。
- **英語を隠す** (既定 ON)。日本語を見て自分で英語を言い、「英語を見る」で答え合わせ。
  **出した英文はタップするともう一度隠せる** (`jaen-en-toggle`)。同じ文を何度も練習するとき用。
  カードごとの指定は上のスイッチを切り替えるとリセットされる。
  上から順に開いていったあとは、**画面の下に出る「🙈 英文をぜんぶ隠す (n)」** で一斉に閉じられる。
  ボタンは開いた英文が 1 つでもある間だけ固定表示 (`.jaen-hide-all`)。リストの下の方まで
  スクロールしても押せる。リロードと違って絞り込みもスクロール位置もそのまま。
  開け閉めの状態は親の `openIds` で持っているので、何枚開いているかを数字に出せる。
  「今日の練習」でも同じで、隠しても判定ボタンと 🔊 は残るので、言い直してから判定できる。
- 🔊 で英文・チャンクを読み上げ。
- **◎ ○ △ ×** の 4 段階評価と、違和感メモ。
- 🎙 で **自分の声 / お手本音声** を録音・再生 (既存の `PhraseAudioRecorder` を再利用)。
  録音を開くタイミングでその文を自作フレーズとして実体化する。
- ◎ ○ を付けた文をまとめてフレーズ化 → Practice タブの音読・暗唱・Voice Energy へ。
- 評価つき JSON / TSV の書き出しと、JSON の読み込み (別端末への引き継ぎ)。

## 分野ごとのメモと周回カウンター (`jaDomainNote.ts`)

分野の一覧の先頭に、**その分野をどう回すか自分で決めて数える欄**を置いている。
「とりあえず 21 周まわす」のような練習の仕方を支えるためのもので、
**アプリ側は中身を一切解釈しない** (SRS にも XP にも街にも影響しない)。

- **周回カウンター**: ＋ / − で増減。0 未満にはしない。
- **自由メモ**: 何周目まで終わったか、詰まっている文、など何でも。入力するたびに保存。
- 保存先は `localStorage["eigochan.jaDomainNote.v1"]`。分野番号 → `{ note, rounds, updated }`。
- 評価つき JSON の書き出し・読み込みに乗せてあるので、端末を移しても引き継げる
  (`domains` フィールド。古い書き出しには無いが、無くても読める)。
- 検索中は分野をまたぐので出さない。

なぜカウンターと自由メモの両方かというと、回数はテキストに書き足すと面倒で、
逆に回数だけだと「どこで詰まったか」が残らないため。

## 練習タイマー (`practiceTimer.ts` / `PracticeTimer.tsx`)

40 文を前にして時間の枠が無いと、練習が始まらないまま眺めて終わりやすい。
そこで **「1 周ぶんの持ち時間」** を測るタイマーを画面下に置いている。

- 単位は **1 周**。周回カウンターと同じ単位にそろえてある
  (1 文ごとに測ると、止めたり進めたりが忙しくて練習にならない)。
- **音は鳴らさない。** 0 になったらピルの色が変わって数回ふくらむだけ。
  声を出している最中に音が鳴ると集中が切れるため。`prefers-reduced-motion` では動かさない。
- 残りは **ピルの背景が減っていく形** でも見せる (`--left`)。数字を読まなくても分かる。
- 押すたびに 開始 → 一時停止 → 再開。↺ で最初から。0 のあとに押すともう一周。
- 残り時間は毎回 **「終わる時刻」から計算** する。画面を止められても数字がずれない。
- 秒数は周回カウンターの隣で選ぶ (`使わない / 1 / 3 / 5 / 10 / 15 / 20 分`)。
  端末ごとの設定で `localStorage["eigochan.jaTimer.v1"]`。**「使わない」で非表示**。
- 選ぶときの助けに **1 文あたりの目安** を出す (10 分 ÷ 40 文 = 約 15 秒)。
- ページを離れると止まる (画面の中だけの状態。分野を切り替えても走り続ける)。

## 英会話の型 (分野 79〜86)

**枠を覚えて中身を差し替える** ための分野。1 文が `pat` に型を持つ
(`"Are you sure ~?"` `"I'm about to ~"` など、現在 113 種類 / 320 文)。

- 型の一覧は YouTube 動画から本人が集めた資料をもとにしているが、
  **例文はそのまま使わず、本人が実際に言う場面で書き直している**。
  - 資料の日本語が「あなたは〜と確信していますか？」のような直訳調で、
    このコーパスの「実際に口から出る日本語」と噛み合わないため。
  - 他人の例文集をそのまま Public リポジトリに入れない、という理由もある (DUO と同じ扱い)。
- 型は文法の枠組みなので、資料どおり網羅している。中身だけが自前。
- **型は答えのヒントになるので、英文を出したときだけ見せる。**
  日本語だけが見えている状態で `型: Are you sure ~?` が出ていると、
  日→英の練習にならない。一覧のカードも「今日の練習」も同じで、
  英文を隠すと型も一緒に消える。
- **検索欄に型を入れれば横断で拾える** (分野をまたいで同じ型を集められる)。
- 1 つの型に **2〜3 文** 置く。1 文だけだと「この型はこの文」と丸暗記になって、
  枠として使えるようにならないため。

同じ型の文が複数の分野に散っていてよい。型で検索すれば集められる。

## チャンク (分野 87〜89)

型が「文の枠」なら、チャンクは **文の部品**。分野 87・88 が動詞のかたまり
(`figure it out` `put up with` など)、89 が言い出しと補足
(`I'm about to ~` `just in case` など)。現在 70 種類 / 120 文。

- 型と同じ `pat` に入れている。別のフィールドを足すと検索・表示・出題の
  すべてに分岐が増えるわりに、練習中の見え方は「枠が出る」で同じだから。
  したがって **英文を出したときだけ見える** ルールもそのまま効く。
- 既存の分野に **無いチャンクだけ** を入れている (`get up` `take a shower` は
  分野 01 などに既にあるので重複させない)。追加時は必ず重複チェックを回す。
- 1 チャンクにつき原則 2 文。型と同じ理由で、1 文だと丸暗記になる。

## 組み合わせ練習 (`/ja-en/build`)

`言い出し × 動詞 × 補足` を 1 つずつ引いて、その 3 つで自分で文を作る画面。
部品は `src/data/chunkBuilder.ts` の `OPENERS` (40) / `VERBS` (60) / `EXTRAS` (30)
で、組み合わせは 72,000 通り。

- **正解の英文を持たない。** 組み合わせ次第でいくらでも作れるので、
  「思い出せたか」を判定できない。答え合わせは自分でする。
- したがって **SRS にも XP にも街にも乗せない**。乗せると
  「押せば伸びる」ボタンになって、今日の練習の報酬設計が壊れる。
  代わりに `chunkPractice.ts` が **組み立てた回数だけ** を数える
  (`localStorage["eigochan.chunkPractice.v1"]`、今日ぶんは JST 日付で 0 に戻る)。
- 🔀 の引き直しは **数えない**。使いにくい組み合わせを飛ばすためのもので、
  回数を稼ぐためのものではないから。
- 日本語の意味は出したり隠したりできる。慣れてきたら英語の部品だけで組む。

なぜ「今日の練習」と分けたか: 決まった文を **思い出す** 練習と、
部品から **組み立てる** 練習は頭の使い方が違う。同じ画面に混ぜると
どちらの成績なのか分からなくなるので、画面も記録も分けている。

## 保存とプライバシー

- 評価とメモは `localStorage["eigochan.jaCorpusReview.v1"]` にこの端末だけで保存。
  **D1 同期には乗せていない** (同期しているのは Phrase と進捗)。
  端末をまたぐときは JSON を書き出して読み込む。
- フレーズ化した文は通常の自作フレーズなので、同期を有効にしていれば同期される。
- 音声メモは従来どおり IndexedDB (+ 任意で R2)。

## 分野の作りかた (運用)

1. `src/data/jaCorpus/dNN<名前>.ts` を作り、`DNN_SELF` (本人の文) と `DNN_ADD`
   (追加案) の 2 配列を書く。ID は SELF → ADD の順に通し番号が振られる。
2. `src/data/jaCorpus/index.ts` の `RAW_BY_DOMAIN` に 1 行足す。
3. 画面で ◎ ○ △ × を付けながら読み、違和感はメモに書く。
4. △ × とメモを次の分野の作成方針に反映する (進むほど自分の言い回しに寄る)。

目標は 89 分野 × 平均 40 文 = **約 3,560 文**。数合わせはせず、

- 本当に使いそう
- 似すぎていない
- 音声で繰り返す価値がある
- 単語だけ差し替えて応用できる

を満たす文だけを残す。


## 今日の練習 (SRS)

`/ja-en/today` は、間隔反復で選んだ 3 文を 1 文ずつ出す画面 (`DAILY_PLAN_SIZE`)。

1. 日本語だけを出す → 声に出して英語で言う
2. 「英語を見る」で答え合わせ (英文・チャンク・読み上げ)
3. **✕ 言えなかった / ○ 言えた / ◎ すぐ言えた** を自分で選ぶ

### 出題の決め方 (`dailyPlan.ts`)

1. **期日が来た文** を、期日が古い順 → 落とした回数が多い順に入れる。
2. 残り枠を **新規の文** で埋める。出題ずみが少ない分野 → 重要度 (`must` 優先)
   → 分野番号 → 分野内の並び順。1 分野に固まらないよう同じ分野は最大 4 文。

### 出題の範囲を絞る (`practiceFocus.ts`)

**「今週は RealFi のコールが近いので RealFi だけ」** も
**「今日は 41. オンライン会議だけ」** も、同じ 1 文ずつの流れで練習できるようにするための仕組み。
`localStorage["eigochan.practiceFocus.v1"]` に入れる。

```ts
type PracticeFocus =
  | { kind: "all" }                      // 全分野 (既定。localStorage には書かない)
  | { kind: "group"; group: string }     // グループ 1 つ
  | { kind: "domain"; domain: number };  // 分野 1 つ
```

- 絞ると **復習も新規もその範囲だけ** から選ばれる (今日の 3 文が全部その分野になる)。
- 範囲の外に期日が来ている文があれば、その数だけ画面下に出す (黙って消さない)。
- 絞っても **SRS・XP・街・録音は共通**。別モードにしていないので、
  1 分野だけやった日も街全体が育つし、連続日数も途切れない。
- 切り替えは `/ja-en/today` の「出題の範囲」。グループごとの `<optgroup>` に
  「〇〇 ぜんぶ」+ その中の分野が並ぶ。Home にも今の範囲が出る。
- **入口**: `/ja-en` の「分野を選ぶ」から「この分野を 1 文ずつ練習する →」で
  `/ja-en/today?domain=NN` に飛ぶ (`focusFromParams`)。URL の指定は保存もされるので、
  次に開いたときも同じ範囲で始まる。
- 範囲を絞っている間は「触れた n/N 文」のバーを出す。分野 1 つなら 40 文なので終わりが見える。
- 旧形式 (グループ名の文字列をそのまま保存していた頃) の値も読めるようにしてある。

分野やグループを増やしたいときは `domains.ts` に足すだけで、この仕組みに乗る。

### 間隔の伸び方 (`srs.ts`)

SM-2 を単純化したもの。`ease` は 1.3〜2.8、初期値 2.3。

| 判定 | 次の間隔 |
| --- | --- |
| ✕ 言えなかった | 0 日 (今日中にもう一度)。ease −0.2、lapses +1 |
| ○ 言えた | 初回 1 日 / 2 回目以降は `間隔 × ease` |
| ◎ すぐ言えた | 初回 3 日 / 2 回目以降は `間隔 × ease × 1.3`。ease +0.05 |

### XP (`JA_XP_RULES`)

**報酬は「思い出せたこと」に付ける。** 同じ文を連打しても間隔が伸びないので XP も伸びない。

| 条件 | XP |
| --- | --- |
| はじめて触れた文 (○ / ◎) | 2 |
| 期日が来た文を言えた | 15 |
| そのとき間隔が 7 日以上だった | +5 |
| そのとき間隔が 21 日以上だった | +5 (7 日ぶんと合算) |
| 前に落とした文 (lapses > 0) を取り戻した | +8 |
| ✕ 言えなかった | 0 (減点はしない) |

XP は既存の `applyPractice()` に流し込むので、レベル・ストリーク・街はそのまま動く。
セッションを途中で離れても、そこまでの XP は画面を離れるときに反映される
(`PracticeLog.phraseId` は `jaen_today_<日付>`。Log 画面ではこの ID を見て
「日→英モード 今日の練習」と表示する)。

SRS の状態は `localStorage["eigochan.jaSrs.v1"]`。評価・メモと同じくこの端末だけで、
D1 同期には乗せていない。`masteryByDomain()` は分野ごとの定着状況を返すので、
「街を分野に紐づける」ときはこれを使う。


## 街を分野に紐づける (`cityDistricts.ts` / `CityDistricts.tsx`)

**1 分野 = 1 街区 (現在 86 街区)。** 街の成長上限をレベル表ではなくコーパスに合わせる。
街は画像ではなく SVG で描くので、定着状況に応じて毎回姿が変わる。

| stage | 見た目 | 条件 |
| --- | --- | --- |
| 0 | 更地 (点線の区画) | まだ 1 文も出していない |
| 1 | 建てはじめ | 1 文以上出した |
| 2 | 建物が立つ | その分野の 25% 以上に触れた |
| 3 | 灯りがつく | 間隔 21 日以上の文が 25% 以上 |
| 4 | 育ちきり (屋上の光) | 同 60% 以上 |

**劣化**: 期日を過ぎた文が溜まると、その街区の灯りが暗くなる (`brightness`
は最低 0.25 まで)。建物は壊れない。復習すれば戻る。

街区をタップすると分野の状態が出て、`/ja-en?domain=NN` でその分野の文に飛べる。

### 街区の吹き出し (`districtVoices.ts`)

街区をタップすると、**その分野で実際に練習した文** が吹き出しで出る。
まだ 1 文も出していない分野は「声が聞こえません」と出るだけ (更地なので当然)。

- 出す順は **間隔が長い順** = その街に根づいた言葉から。
- 🔀 で別の文に切り替わる (`nextVoiceIndex` は順送りではなく毎回ばらけさせる)。
- 吹き出しのしっぽは `plotCenterPercent()` が返す位置に合わせるので、
  タップした建物の真下から出ているように見える。ズーム表示でも合う。

### 見た目

- **時間帯** (`cityPhaseAt()`): 朝 5-10 / 昼 10-17 / 夕方 17-20 / 夜 20-5 で空・地面・
  道路の色が変わる。夜は月と星が出て、灯りのにじみが強くなる。
  開発用に `/city?phase=morning|day|evening|night` で強制表示できる。
- **グループ色**: 9 グループそれぞれに建物の色 (`is-g0`〜`is-g8`)。グループを足したら
  この CSS も 1 組足す (足さないと色なしの街区になる)。
- **道路・木・屋根**: 各行に道路。更地の一部には木が生える。屋根の形 (三角/陸屋根) は
  分野 ID から決まるので、同じ分野は毎回同じ姿になる。
- **ズーム**: グループタブで 1 グループだけを大きく表示 (`zoomGroup`)。
  この表示では分野番号と名前が街区の下に出る。

## 出題のシャッフル

「今そういう気分じゃない文」に当たったときに、引き直せるようにしてある。

| 場所 | ボタン | 動き |
| --- | --- | --- |
| Home の今日のフレーズ | 🔀 別のフレーズ | 今日のミッションのフレーズを引き直す (`pickRandomPhraseId`)。今日すでに達成ずみなら `completed` は保つので、ミッションボーナスは 1 日 1 回のまま |

引き直しは常に「今出ている文以外」から選ぶので、押して何も変わらないことはない。

## 続け方の指標

連続日数は 1 日休むと 0 に戻るので、離脱の引き金になりやすい。
そのため「あなたのきろく」では **今週の練習日数 (直近 7 日 / 目標 3 日)** を主に見せる。
`weeklyPractice()` が直近 7 日の点を返す。ヘッダの 🔥 連続日数はそのまま残してある。

## 声を出したボーナス

録音した音声の Voice Energy が閾値 (`VOICE_BONUS_MIN_SCORE = 20`) を超えたら、
1 文につき 1 回だけ +3 XP。**音量を競わせないよう、超えたかどうかだけを見る。**
