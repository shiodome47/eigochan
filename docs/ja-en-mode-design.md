# 日→英モード (JA→EN) 設計メモ

「自分が実際に言いそうな日本語」を大量に並べ、それを英語に置き換えて練習するモード。
既存の英語主役のフレーズ機能とは **別モード** として作り、必要になった文だけを
既存のフレーズ (音読・暗唱・録音) に流し込む。

## 全体像

```
src/data/jaCorpus/        日本語コーパス本体 (リポジトリ内の静的データ)
  types.ts                JaDomain / JaSentenceInput / JaSentence
  domains.ts              66 分野 × 6 グループの定義 (target = 目標文数)
  d01Morning.ts 〜 d10Planning.ts   分野 01〜10 の文 (各 40)
  index.ts                ID 採番・検索・集計。分野を書いたらここに 1 行足す

src/utils/jaCorpusReview.ts  評価(◎○△×)・メモ・書き出し・フレーズ化
src/pages/JaEnPage.tsx       /ja-en の画面
```

## データ 1 文が持つ情報

| フィールド | 内容 |
| --- | --- |
| `ja` | 自分が実際に言いそうな完全な日本語 |
| `en` | 会話で自然に使える英語 |
| `ch` | 反復して覚える英語のチャンク |
| `scene` | 場面 (家、駅、カフェ、仕事 など) |
| `to` | 相手 (家族、友人、店員、同僚 など) |
| `imp` | 重要度 `must` (必須) / `often` (よく使う) / `sub` (補助) |
| `by` | 出所 `self` (本人が書いた文) / `add` (口調を寄せて足した提案文)。データファイル側では `*_SELF` / `*_ADD` の 2 配列に分けて書き、`index.ts` で付与する |

読み上げは `en` をそのまま Web Speech API に渡すので、音声用の別フィールドは持たない。

## ID 規約

`d<分野番号2桁>_<分野内連番3桁>` (例: `d01_003`)。

- 連番は **配列の並び順から自動採番** する (データ側に id は書かない)。
- そのため **既存の文を途中に挿入したり並べ替えると、評価が別の文にずれる**。
  - 追加は原則 **末尾に足す**。
  - 文を差し替えたときのために、評価には「評価した時点の日本語」を一緒に保存していて、
    ずれた文はカードに ⚠ を出す。
- フレーズ化したときの Phrase ID は `custom_jc_d01_003`。`custom_` 始まりなので
  既存の自作フレーズ・音声メモ・同期にそのまま乗り、何度取り込んでも増殖しない。

## 画面でできること

- 分野を選ぶ (グループ 6 つ → 分野のプルダウン)。全分野横断の検索も可。
- **英語を隠す** (既定 ON)。日本語を見て自分で英語を言い、「英語を見る」で答え合わせ。
- 🔊 で英文・チャンクを読み上げ。
- **◎ ○ △ ×** の 4 段階評価と、違和感メモ。
- 🎙 で **自分の声 / お手本音声** を録音・再生 (既存の `PhraseAudioRecorder` を再利用)。
  録音を開くタイミングでその文を自作フレーズとして実体化する。
- ◎ ○ を付けた文をまとめてフレーズ化 → Practice タブの音読・暗唱・Voice Energy へ。
- 評価つき JSON / TSV の書き出しと、JSON の読み込み (別端末への引き継ぎ)。

## 保存とプライバシー

- 評価とメモは `localStorage["eigochan.jaCorpusReview.v1"]` にこの端末だけで保存。
  **D1 同期には乗せていない** (同期しているのは Phrase と進捗)。
  端末をまたぐときは JSON を書き出して読み込む。
- フレーズ化した文は通常の自作フレーズなので、同期を有効にしていれば同期される。
- 音声メモは従来どおり IndexedDB (+ 任意で R2)。

## 分野の作りかた (運用)

1. `src/data/jaCorpus/dNN<名前>.ts` を作り、`DNN_SELF` (本人の文) と `DNN_ADD`
   (追加案) の 2 配列を書く。ID は SELF → ADD の順に通し番号が振られる。
2. `src/data/jaCorpus/index.ts` の `RAW_BY_DOMAIN` に 1 行足す。
3. 画面で ◎ ○ △ × を付けながら読み、違和感はメモに書く。
4. △ × とメモを次の分野の作成方針に反映する (進むほど自分の言い回しに寄る)。

目標は 66 分野 × 平均 40 文 = **約 2,640 文**。数合わせはせず、

- 本当に使いそう
- 似すぎていない
- 音声で繰り返す価値がある
- 単語だけ差し替えて応用できる

を満たす文だけを残す。
