# eigochan

英語を声に出すほど、街が育つ。音読・暗唱・録音で英語を体に入れる PWA。

## 特徴

- **Local-first**: 既定では何もサーバに送りません。フレーズ・進捗・音声メモはすべてブラウザの中(localStorage / IndexedDB)に保存されます。
- **オフラインで使える PWA**: Service Worker で precache し、電波がなくても起動します。
- **音声メモ**: マイクで録音した「お手本音声」「練習音声」を端末内に保存し、再生できます。
- **オプションで PC/スマホ同期**: Cloudflare Pages Functions + D1 + R2 を使った同期機能を、後付けで有効化できます。

## 開発(同期機能なし)

これだけで完結します。サーバ設定なし、ログインなし。

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ に PWA 一式
npm run typecheck
```

ホスティング先は静的ファイルが置ければ何でも OK(Cloudflare Pages / Netlify / Vercel / GitHub Pages 等)。

## ホーム画面に追加する (スマホ)

アイコンから開けるようにすると、次からアプリのように起動できます。Home の下に案内カードを出しています(追加ずみなら出ません)。

| 端末 | 手順 | 注意 |
| --- | --- | --- |
| iPhone / iPad | **Safari** で開く → 共有ボタン □↑ → 「ホーム画面に追加」 | iOS はブラウザ側から追加ダイアログを出す API が無いため、案内のみ。**LINE / X などのアプリ内ブラウザからは追加できません**(共有メニューが無いため)。まず Safari で開き直してください |
| Android | Chrome のメニュー ⋮ → 「アプリをインストール」。`beforeinstallprompt` が取れた端末では案内カードの **📲 ホーム画面に追加する** から 1 タップでも実行できます | このイベントは「未インストール」かつ Chrome が条件を満たしたと判断したときにしか飛ばないので、**来なくても手順は必ず出す** 作りにしています |

`beforeinstallprompt` はモジュールの読み込みより前に 1 度だけ飛んでくることがあるため、
`index.html` のインラインスクリプトで受け止めて `window.__eigochanInstallEvent` に置き、
`src/utils/installPrompt.ts` がそれを引き継ぎます。取り逃がすとボタンを二度と出せません。

追加できるための条件 (HTTPS / `manifest.webmanifest` / 192・512px アイコン / Service Worker) はリポジトリ側で満たしています
(`vite.config.ts` の `VitePWA`、`public/pwa-*.png`、`index.html` の `apple-touch-icon`)。
うまくいかないときはまず **開いているブラウザ** を確認してください。

### 画面が古いままのとき

Home の一番下に **ビルド時刻** (`更新 YYYY/MM/DD HH:mm`、`vite.config.ts` の `__BUILD_STAMP__`) を出しています。
デプロイしたのにこの値が変わらない場合は、配信ではなく **端末側の Service Worker キャッシュ** が残っています。
Chrome なら「設定 → サイトの設定 → 全データ削除」、または一度タブを全部閉じてから開き直すと入れ替わります。

## オプション:PC/スマホ同期を使う場合

「自分用に PC とスマホで同じデータが見えてほしい」場合のみ、Cloudflare 側のセットアップを行います。**有効にしないユーザーには影響しません**。

### 必要なもの

- Cloudflare アカウント(Workers/Pages 無料枠で十分)
- Cloudflare Pages 上の eigochan プロジェクト
- Wrangler CLI(`npm install -g wrangler`)

### セットアップ

詳細は [DEPLOY.md §10](./DEPLOY.md) を参照。要約:

```bash
# D1 と R2 を作成し、wrangler.toml の database_id を埋める
wrangler d1 create eigochan-sync
wrangler r2 bucket create eigochan-audio
wrangler d1 migrations apply eigochan-sync --remote
```

`wrangler.toml` をコミットすれば、Cloudflare Pages が自動でビルド・デプロイし、`/api/*` の Pages Functions が D1/R2 にバインドされます。

### 同期の使いかた

Log タブ → 「この端末のデータを同期する」セクション。

| 操作 | 何が起きるか |
|---|---|
| **同期コードを作成**(PC で初回) | 256bit の同期コードを発行し、現在のローカルをサーバにアップロード |
| **同期コードで参加**(スマホで初回) | コードを入力 → サーバから取得してローカルに反映 |
| **📤 サーバへ送信(全件)** | 現在のローカル(フレーズ・進捗)をサーバに反映 |
| **📥 サーバから取り込む(全件)** | サーバ側でローカルを上書き(確認ダイアログあり) |
| **音声メモをサーバへアップロード** | IndexedDB の音声を R2 に手動アップロード |
| **音声メモをサーバから取り込む** | R2 の音声を IndexedDB に手動ダウンロード |
| **保存量を更新** | ローカルとサーバの音声件数・サイズを表示 |
| **同期を解除** | この端末から syncCode を消す(サーバデータは残る) |

> **注意**: フレーズ・進捗・音声メモは現状**自動同期されません**。各操作はユーザーがボタンを押したタイミングで実行されます。差分同期や自動 push/pull は将来の拡張候補です。

### 同期コードの扱い

- syncCode は **パスワード相当** です。漏らさないでください。
- D1 には SHA-256 ハッシュのみ保存しています(生コードはサーバに残りません)。
- 失効・再発行は現状未実装。漏れた場合は対象アカウント側の D1 を作り直す運用です。詳細は [DEPLOY.md §13](./DEPLOY.md) 参照。

## ひとりごと英語 (Monologue English)

頭に浮かんだ日本語を、まずそのままアプリに保存できます。英語はあとで入力できます。

- フレーズ一覧の **「💭 ひとりごとを追加」** から、日本語だけを保存できます (英語空欄OK)。
- あとで編集画面を開いて、自分が言いたい英語を入力してください。
- 英語が入ると、**通常のフレーズと同じ** 音読・暗唱・録音・Voice Energy 練習に進めます。
- AI APIによる **自動翻訳・自動添削はしません**。ChatGPT / Claude / 辞書などをユーザー自身が参照しながら、自分の英語を手で入力する想定です。
- カードの状態バッジ: `⏳ 英語待ち` (英語未入力) / `✅ 練習OK` (英語入りずみ) / `✓ 練習済み`。
- ローカル保存。同期コードを設定していれば既存の同期に乗ります。作成日時メタ (`thoughtCreatedAt`) も migration `0003_phrase_thought_created_at.sql` 適用後は D1 同期で維持されます。

## 日→英モード (JA→EN)

「自分が実際に言いそうな日本語」を並べ、それを英語に置き換えて練習する別モードです (`/ja-en`)。

- 日本語コーパスは **リポジトリ内の静的データ** (`src/data/jaCorpus/`)。現在は **105 分野 / 10 グループ / 3,968 文** (本人の文 1,314 + 追加案 2,654)。日本語・英語とも重複ゼロです。
- 1 分野は **本人が書いた 20 文 (`*_SELF`) + そこに口調を寄せた追加案 20 文 (`*_ADD`)** で構成。カードの「本人の文 / 追加案」タグと出所フィルタで切り替えられます。
- **今日の練習** (`/ja-en/today`): 間隔反復 (SRS) で選んだ 3 文を 1 文ずつ出します (気が向いたら画面から足せます)。日本語 → 自分で英語を言う → 答え合わせ → **✕ / ○ / ◎** の自己判定。判定に応じて次の出題日が伸び、XP は「思い出せたこと」に対して入ります (同じ文を連打しても増えません)。
- 気分に合わない文に当たったら **🔀 別の文にする** で今の 1 文だけ入れ替えられます (判定しないので SRS には影響しません)。同じように、Home と練習画面の「今日のフレーズ」も **🔀 別のフレーズ** で引き直せます。
- 既定で **英語は隠れています**。日本語を見て自分で英語を言ってから「英語を見る」で答え合わせ。
- 分野の一覧の先頭に **その分野のメモと周回カウンター** があります。「とりあえず 21 周まわす」のような自分の練習の仕方を記録するための欄で、アプリ側は中身を解釈しません (SRS・XP・街には影響しません)。評価つき JSON に乗るので端末を移しても引き継げます。
- 画面の下に **練習タイマー** があります。「この分野を 10 分で 1 周」のように 1 周ぶんの持ち時間を測るもので、押すとカウントダウンが始まります。**音は鳴りません** (時間が来たら色が変わるだけ)。秒数は周回カウンターの隣で選べ、「使わない」で非表示にできます。
- 1 文ごとに **◎ よく使う / ○ 言いそう / △ あまり言わない / × 自分らしくない** を付け、違和感はメモに残せます。この評価をもとに、次の分野の日本語を作り込んでいきます。
- 🔊 の読み上げは **端末に入っている英語の声** を使います。macOS などに標準で入っているジョーク音声 (`Albert` `Whisper` `Zarvox` など) は候補から除外し、聞き取りやすい声を優先して選びます。合わなければ **🗣 読み上げの声** で選び直せます (端末ごとに保存)。
- 🎙 から **自分の声・お手本音声** を録音・再生できます (既存の音声メモと同じ仕組み)。
- ◎ ○ を付けた文は「フレーズに取り込む」でいつもの自作フレーズになり、Practice タブの音読・暗唱・Voice Energy がそのまま使えます。
- 評価とメモは同期コードを設定している場合、フレーズ・進捗と一緒にクラウドへ同期されます。同期を使わない場合は **この端末の localStorage のみ** に保存されます。

- **出題の範囲を絞る**: 「今日の練習」の **出題の範囲** で、**グループ単位** (例: RealFi ぜんぶ) でも **分野単位** (例: 41. オンライン会議) でも絞れます。絞るとその日の 3 文が全部そこから出ます。分野一覧の「この分野を 1 文ずつ練習する →」からも入れます。別モードにはしていないので、SRS・XP・街・録音はそのまま共有されます。
- **RealFi**: 分野 67〜78 が RealFi グループ (240 文)。67〜72 が **コールの進行** (入り方 / 進捗報告 / 反応 / 現場と数字 / 資金 / 決めごと)、73〜78 が **Office Hours で実際に出た話題** (テストネットの数字 / SPO 加速プログラム / ステーブルコインと利回り / 流動性と DeFi 連携 / ロードマップと監査 / 不具合報告)。後者は週一回の文字起こしを読んで足していきます。
- **英会話の型**: 分野 79〜86 は「型」で構成した分野です (320 文 / 113 種類の型)。`Are you sure ~?` `I'm about to ~` のような**枠**を覚えて中身を差し替える練習用です。型は **英文を出したときだけ** カードに出ます (日本語だけ見えている間に出るとヒントになってしまうため)。検索欄に型を入れると分野をまたいで集められます。型の一覧は集めた資料に沿っていますが、**例文はこのアプリの文体で書き下ろしたもの**です。
- **チャンク**: 分野 87〜89 はチャンク (かたまり) で構成した分野です (120 文 / 70 種類)。87・88 が **動詞のかたまり** (`figure it out` `put up with` など)、89 が **言い出しと補足** (`I'm about to ~` `just in case` など)。型と同じ枠に入れているので、検索欄からも分野をまたいで集められます。
- **組み合わせ練習** (`/ja-en/build`): **言い出し × 動詞 × 補足** を 1 つずつ引いて、その 3 つで自分で文を組み立てる画面です (40 × 60 × 30 = 72,000 通り)。決まった文を思い出す「今日の練習」とは頭の使い方が違うため、**正解の英文は出さず**、SRS・XP・街には乗せません。組み立てた回数だけ数えます。噛み合わない組み合わせ (`put up with` に目的語がない、「これからの話」に `the other day` が付く など) はわざと残してあり、代わりに 💡 の短い注意書きが出ます。
- **暮らしの場面**: 分野 90〜99 は「相手と一緒に一つのことを進める」場面の分野です (400 文)。買うものを選ぶ / ネットの不調を直す / 部屋の温度を調節する / お金の話をする / 好き嫌いを話す / 昔の話をする / 散歩と動物園 / ペットを飼う相談 / 落ち込んだ相手を励ます / 二人で手分けして進める。日常生活 01〜10 が「自分の動き」なのに対して、こちらは **往復のある会話** を言えるようにするための分野です。
- **短い受け答え**: 分野 100 は 1〜3 語の返し (`True.` `Same here.` `Lucky you.` `Leave it to me.` など) だけを集めた分野です。長い文が言えても、この一言が出てこないと相手の話が続きません。101〜105 は 90〜99 で拾いきれなかった場面 (看病する側 / なくし物を一緒に探す / 同僚の仕事を手伝う / 見送りと再会の約束 / 泊まる宿を比べて決める)。
- **分野の街** (`/city`): 分野の数だけ街区があり、思い出せる文が増えると建物が育ち、灯りがつきます。街区をタップすると、**その分野で覚えた文が吹き出しで出ます** (🔀 で別の文へ)。

分野の追加手順やデータ形式は [docs/ja-en-mode-design.md](./docs/ja-en-mode-design.md) を参照。

## 市販教材データの取り扱い

eigochan は **市販教材 (DUO 3.0 など) の本文・音声をリポジトリに同梱しません**。

アプリ本体 (UI / コード) は Public のまま、教材データは各ユーザーが自分の手元で Import して使う設計です。

- フレーズには `source` (`"initial" / "original" / "duo3" / "monologue"`) と、必要に応じて `sourceSection` / `sourceIndex` を持たせられます。
- 「DUO 3.0」を選んだフレーズは、フレーズ一覧の出典フィルタから Section 単位で絞り込めます。
- 音声メモ (お手本 / 練習) は、DUO 由来のフレーズでも他と同じ仕組みで個別に録音・保存・同期できます。
  - DUO のセクション単位 MP3 を一括取り込みする機能は現状ありません。必要なフレーズだけ個別に紐づけてください。
- 自分の正規購入物・利用権限の範囲内で、自分の端末にのみ取り込んで利用してください。
